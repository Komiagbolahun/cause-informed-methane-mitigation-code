# cause-informed-methane-mitigation-code

# Cause-Informed Framework for Risk-Targeted Methane Emission Mitigation

Code accompanying:

**Adekomi, A. A., Yang, S. L., Stokes, S. & Ravikumar, A. P.** Cause-informed framework
for risk-targeted methane emission mitigation in oil and gas operations.
*Nature Communications* **17**, 5991 (2026).
https://doi.org/10.1038/s41467-026-72607-1

This repository is a mirror of the official, verified-reproducible Code Ocean capsule:
**https://doi.org/10.24433/CO.7756173.v1** — that capsule is the canonical, independently
verified source and the one cited in the published paper.

## What this code does
Statistical hypothesis testing (chi-square tests for temporal/inter-operator variation),
an escalation-ratio metric quantifying super-emitter risk by causal category, a
quantitative FMEA/fault-tree risk-scoring framework, a 1,000-iteration Monte Carlo
sensitivity analysis testing robustness to data misclassification, and a framework towards 
a predictive framework for risk-targeted emissions mitigation in energy operations.

## Data
Anonymized causal analysis data and source data for all figures are available on Figshare:
https://doi.org/10.6084/m9.figshare.29877581
